=========================================================
 gimbal_ctl (Windows) —— 云台/底盘控制上位机  使用说明
=========================================================

【能跑的机器】
  Windows 10 / Windows 11，64 位。
  不用装任何运行库（exe 是静态链接的），拷过去双击就行。


【第一次用：先自检，再开窗口】

  1) 双击 start.cmd  （或直接在 cmd 里跑 gimbal_ctl.exe --selftest）
     看输出的自检结果：
       全部通过  -> UDP 链路通，可以往下走
       "收到 Jetson 遥测回包" FAIL -> Jetson 上 gimbal 没跑，或者 IP 不对

  2) 双击 start.cmd 正式运行（不带参数 = 用 gimbal_ctl.ini 里的配置）
     窗口出来后，**先点一下窗口**让它拿到焦点，键盘才开始生效。
     左上角如果红字写着 NOT FOCUSED，就是没点到。

  3) 退出：按 Esc（会自动给 Jetson 发一帧"停手"），或者点窗口右上角 X。


【连哪台 Jetson：改 gimbal_ctl.ini】

  网线直连（笔记本 192.168.2.1 <-> Jetson 192.168.2.2）：
      host=192.168.2.2          <- 默认就是这个

  走 Jetson 热点 MECAR-CTRL / 密码 mecar12345：
      host=10.42.0.1            （Jetson 侧要先 sudo nmcli con up car-ap）

  改完保存，重新双击即可。临时改参数也可以直接带命令行参数：
      gimbal_ctl.exe --host 10.42.0.1 --no-video --gimbal-rate 150

  ini 里的其它可调项（速度、平滑、窗口大小、小陀螺速率）都有中文注释。


【按键】

  云台（按住转，松开平滑停）
      ↑ / ↓          抬头 / 低头（pitch）
      ← / →          左转 / 右转（yaw）

  底盘（默认按【枪口】方向走，不是车头）
      W / S          沿枪口指向 前 / 后
      A / D          枪口的 左 / 右 侧（麦轮横移，车头会歪着走，正常）
      Q / E          车体左转 / 右转（枪口跟着车体转）
      Shift          按一下切换 快速档 / 普通档（锁存，不用一直按）
                    普通 300 mm/s、1.5 rad/s；快速 600 mm/s、3.0 rad/s
      T              切换驾驶坐标系：枪口方向 <-> 车头方向
      Y              把【当前枪口指向】标定为"正前"（校正枪口零点）

  安全
      空格           停手 / 继续（HOLD，云台+底盘+发射一起停）
      x              急停（云台+底盘立即停并失能；底盘按 j 恢复）
      g              云台使能开关（界面报 GIMBAL DISABLED 时按两下）
      j              底盘使能开关

  发射（水弹）
      F（按住）      连发；松开停火。HOLD 状态下不响应

  其它
      h              云台回中
      z              当前位置当作 0 度（同时把枪口"正前"标定复位）
      k              清空当前速率（不回中）
      c              底盘里程计清零
      R              小陀螺（底盘自旋 + 云台反向站住），再按一下退出
      v              视频开 / 关
      Esc            退出（会先发停手帧）


【关于"按枪口方向走"】

  界面左上角会显示：
      drive GUN-REL  theta  +35.0 deg      <- 枪口相对车头偏左 35 度
      drive CHASSIS-REL                    <- 按车头方向（按 T 切回枪口方向）

  theta 来自云台遥测（50 Hz），甩枪时车会有约 20 ms 的滞后 —— 这是正常的，
  不是卡顿。想减小滞后就把云台帧率/网线搞稳（用网线直连，别用弱信号热点）。

  车头歪着走是刻意的：麦轮本来就能横移，"枪口朝哪 W 就往哪走"开起来像 FPS
  游戏，对打水弹瞄人比"车头朝前"顺手得多。想老实开车就按 T 切回车体系。

  两种驾驶系都受影响的情况：
    * 遥测断流 -> 自动退回车体系，界面标红 NO TELEM -> fallback to chassis
    * 云台急停/失能（枪不转）-> theta 不变，车照常按最后的枪口方向走

  标定步骤（枪口零点不准时）：
    1) 用 ←/→ 把枪口对准车头正前方
    2) 按 Y  -> 以此刻为准，之后 W 就是这一方向
    3) 想永久生效：把这时的枪口角记下来，改进 gimbal_ctl.ini 的 gun_offset
       或者干脆按 z（云台归零），gun_offset 会自动复位为 0
    4) 验证/纠偏：把云台往左转 90 度，再按 W——
         车应该"横着往左走"（相对车头）。若车往右前方走（左右镜像了），
         说明云台转角符号反了：把 ini 里 gun_sign 改成 -1 即可（A/D 会一起纠正）


【排障】

  双击闪一下就没了 / 黑窗里一堆红字
      -> 用 start.cmd 启动（出错会停下让你看），先跑 --selftest

  NOT FOCUSED（左上角红字）
      -> 鼠标点一下窗口。程序故意这样设计：窗口不在前台就不接受键盘，
         免得你在浏览器里打字把车开走。

  一直 waiting for telemetry
      -> Jetson 上 gimbal 没跑；或者 ini 里 host 写错；或者网线/热点没通。
         先 ping 一下 Jetson：      ping 192.168.2.2
         再确认 gimbal 进程在跑：   ssh 到 Jetson 上 ps aux | grep gimbal

  有状态栏但画面是黑的
      -> Jetson 上 mjpeg_server 没跑（它和 gimbal 是两个程序），或者 v 键关掉了视频。
         浏览器里打开 http://<Jetson IP>:8080/stream 能出图就说明是服务端的事。

  GIMBAL DISABLED / LOCKED
      -> 按 g 两下（关再开）重新授权。yaw 完全不动但底盘正常也是这个原因。

  link 那一行显示 ESTOP / STALL! / WATCHDOG!
      -> ESTOP：按过 x 急停，按 j 恢复底盘
      -> STALL!：电机堵转保护（常见是云台线缆被绞紧），查机械走线
      -> WATCHDOG!：指令流断了（本机卡住/网络断）

  中文乱码
      -> 用 start.cmd 启动（里面已经 chcp 65001）；别用老版 cmd 单独跑 exe。

  SmartScreen 拦了一下（"Windows 已保护你的电脑"）
      -> 没签名的自制 exe 都会提示：点"更多信息" -> "仍要运行"。


【注意】

  * 双击 exe 和直接用 start.cmd 效果一样，start.cmd 多了"出错停窗"和 UTF-8 控制台。
  * 想放桌面快捷方式：右键 gimbal_ctl.exe（或 start.cmd）-> 发送到 -> 桌面快捷方式。
    快捷方式放哪都行，ini 永远从 exe 所在目录读。
  * F 是水弹发射键，抬头就走火不负责；确认波箱电池和枪口方向再按。
  * 车要动的时候别乱数字段。
